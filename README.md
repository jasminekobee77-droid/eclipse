# ECLIPSE – Fashion Magazine

## About My Project

For my Front-End Development project, I decided to create a fashion magazine website called ECLIPSE. I chose fashion because it is something I am interested in.

My website focuses on fashion, beauty, culture and lifestyle. I wanted to keep the website simple, modern and easy to navigate.

## Design

I created my wireframes and website designs using Figma before starting the coding. I looked at Vogue, Hypebeast and Who What Wear for inspiration.

I chose a black-and-white colour scheme because I wanted a clean fashion magazine look.

Figma link: https://www.figma.com/design/WlzMMecT1ZmQFPCFvwcUT0/ECLIPSE-%E2%80%93-Fashion-Magazine?node-id=0-1&p=f&t=flsIH8vtQ08POSOh-0

## Completed Features

- Homepage with featured and latest articles.
- Navigation menu.
- Individual article detail pages.
- Search and category filtering.
- Admin dashboard.
- Add, view, edit and delete articles.
- Article form with validation.
- Reusable Vue components.
- Mobile and desktop layouts.

## How to Run My Website

1. Clone the GitHub repository.
2. Open the project in IntelliJ.
3. Open the terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the localhost link in your browser.

## Challenges

One of the challenges I faced was connecting the different pages and making sure the articles could be accessed from both the homepage and the admin dashboard.

I also had some issues with the article layout and category filtering. I fixed these by making changes to my components and testing them again.

## Limitations

The website uses local reactive state to manage articles. This means that changes made through the admin dashboard will reset when the website is refreshed.

The website does not use a database or backend.

## Reflection
